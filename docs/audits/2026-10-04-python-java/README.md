## Implementation

Starlette now resolves bounded single-assignment string expressions, including
f-strings and known str conversions; stable module declarations may be followed.
Local shadowing of builtin str prevents conversion inference. Direct JSON key
reads yield input fields, whereas assignments to request keys do not become
client requirements. Rebinding prevents that inference. Proven Jinja2Templates
responses use text/html. An unconditionally raising endpoint no longer claims a
successful 200; unresolved exception mapping stays a default response gap.
